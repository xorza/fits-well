# Issues


- A tiled-compressed float image reads a signaling NaN back as a quiet NaN: its tiles decode through an `f64` plane (`src/compress/decode/wide_plane.rs`), and the `f32` → `f64` conversion sets the quiet bit.
- A TAN `Wcs` round trip `world_to_pixel(pixel_to_world(p))` misses `p` by about 7e-12° in world terms: 2e-8 pixel at a corner of astropy's IRAC header (`test_resources/wcs_irac_sip.hdr` without its SIP keywords), and 2.2e-6 pixel at an offset of 1e5 pixels of 1e-6°, where the spacing of a double is far smaller.
- `atomic/wcs/to_pixel/tabular` takes 457 ms a row from commit `e1dcdea` on, and 394 ms at `e1dcdea^`; that commit does not change `src/world_coordinates/tabular/`, whose `locate_one_dimensional` scan holds the time.
- A tiled-compressed float image whose `ZSCALE` or `ZZERO` is a header keyword rather than a table column decodes with a scale of 1 and a zero of 0 (`src/compress/decode/float_quantization.rs`, `Quantized::dequant`); cfitsio takes the keyword's value for every tile (`imcompress.c`, `imcomp_get_compressed_image_par`). With neither column, a lossless read ignores the keywords, where cfitsio applies them. An f32 GZIP image with both as keywords then reads its quantized integers as float bits.
- A tiled-compressed integer image ignores `ZBLANK`, as a keyword and as a column (`src/compress/decode/null_mask.rs`, `NullMask::read` takes `BLANK` alone): nulls stored under `ZBLANK` read as data, and a null mask fails with `MissingKeyword(BLANK)`.
- The HCOMPRESS_1 decoder checks only `nx·ny` against the tile's element count (`src/compress/hcompress.rs`): a stream whose `nx` and `ny` are swapped against the tile decodes transposed, with no error.
- `ImageWriter::write_chunk` sets the writer to `Failed` on an I/O error but never checks that state (`src/fits_writer/image_writer.rs`): a later `write_chunk` appends after the partial bytes, and `finish` signs the HDU and returns `Ok`.
- `FitsEditor::append` checks only that the file length is a multiple of 2880 (`src/fits_editor/mod.rs`): after special records or zero blocks past the last HDU, the appended HDUs are past the point where the reader's scan stops.
- `Value::Text("")` is written padded as `'        '`, which parses back as `" "` (`src/header_model/card/mod.rs`, `write_value`): a null string becomes one blank on every header write.
- `Frame::time_axis_mjd` scales `TIMEOFFS` by the axis's `CUNITi`, not by `TIMEUNIT` (`src/time_coordinates/frame.rs`, `relative_to_mjd_in`): with `TIMEUNIT = 's'`, `CUNIT = 'd'` and `TIMEOFFS = 10`, the time moves by 10 days.
- A `TFORMn` with characters after its code, or after a P/Q `(emax)`, is refused (`src/bintable/tform/mod.rs`); §7.3.1 makes the trailing characters optional and undefined, and §7.3.5 allows more after `emax`. Such a table has no schema and no readable column.
- A P/Q descriptor with a count of 0 and a negative offset is refused (`src/bintable/descriptor/mod.rs`); §7.3.5 makes the offset of a zero-length array undefined.
- A binary-table WCS copies `PVi_m` for m in 0..=20 only (`src/world_coordinates/table_wcs/mod.rs`, `translate`), while TPV reads up to m = 39: a pixel-list or array-column `-TPV` loses its degree-6 and degree-7 terms.
- The ZPN inverse returns its last ζ after 100 false-position steps with no convergence check (`src/world_coordinates/projection/mod.rs`).
- With the `compression` feature off, `Hdu::is_image` still counts a `CompressedImage` (`src/reader/hdu.rs`), so `FitsReader::images` yields HDUs that `FitsReader::image` refuses.
- `verify_checksum` reports `DATASUM = ''` and `CHECKSUM = ''` as `Invalid` (`src/reader/data_checksum.rs`, `is_unknown` requires at least one blank), where cfitsio `ffvcks` reads an empty value as undefined; the editor treats the same `''` as unknown.
- `view_words` is a safe fn whose call into `words::samples` checks its bound with `debug_assert!` alone (`src/image_model/mod.rs`, `src/words.rs`): a wrong byte count is undefined behaviour in a release build.
